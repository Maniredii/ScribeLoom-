# ScribeLoom - Roadmap

## Project Vision
Build a zero-budget AI-powered browser extension that automatically records meaningful user interactions (clicks, navigation, forms), captures screenshots, organizes them into step-by-step tutorials or bug reports, and exports professional documentation.

## Phase 1 — MVP
Goal: Build a working browser extension.

Features:
- [x] Start recording
- [x] Stop recording
- [x] Detect clicks
- [x] Detect navigation
- [x] Detect form submissions
- [x] Capture screenshots
- [x] Organize steps
- [ ] Edit step names manually
- [ ] Preview workflow
- [x] Export JSON (Foundation for PDF)
- [x] Clear session

## Phase 2 — AI Features
Goal: Smart automation.

Features:
- [ ] auto-generated step descriptions
- [ ] step summarization
- [ ] action naming
- [ ] tutorial title generation
